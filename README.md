One image that sums up the world's news of Monday 23 November 2026: a broadsheet front page, "The World in One Day", with the day's lead stories, a stat strip, a world map and a dated news grid. The picture is rendered by `build4.py` (Pillow) from a fact-checked story list; `main.py` copies the finished `entry.png` (1024×1024) to the output, byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
